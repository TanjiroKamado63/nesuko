PRACTICAL NO. 6 – NODE.JS AND EXPRESS FUNDAMENTALS

AIM
a. Install Express and create a simple server.
b. Display a message on the browser using the server response.
c. Create different routes in Express.
d. Send a JSON response from the server.
e. Test routes using browser or Postman.
f. Run the server and observe the output in the console.

INSTALL EXPRESS

Run this command in the terminal:

npm install express


SOURCE CODE – server.js

const express = require('express');

const app = express();

const PORT = 3000;

// Home Route
app.get('/', (req, res) => {
    res.send('Welcome to Home Page');
});

// About Route
app.get('/about', (req, res) => {
    res.send('About Express Application');
});

// Contact Route
app.get('/contact', (req, res) => {
    res.send('Contact Us');
});

// JSON Route
app.get('/student', (req, res) => {
    res.json({
        id: 1,
        name: 'Rahul',
        age: 21,
        course: 'Node.js'
    });
});

app.listen(PORT, () => {
    console.log(`Server running at http://localhost:${PORT}`);
});


HOW TO RUN

1. Save the code in a file named server.js.
2. Open the terminal in the folder containing server.js.
3. Run: node server.js
4. Keep the server running and open these URLs in a browser:

http://localhost:3000/
http://localhost:3000/about
http://localhost:3000/contact
http://localhost:3000/student

EXPECTED RESPONSES

Home route: Welcome to Home Page
About route: About Express Application
Contact route: Contact Us
Student route: JSON data containing id, name, age and course.

The console displays:
Server running at http://localhost:3000
