D. FIND DOCUMENTS WITH SELECTED FIELDS

E. UPDATE EMPLOYEE SALARIES

MongoDB shell query shown in the screenshot:

db.e1.updateMany(
    {"emp_desg": "manager"},
    {"$set": {"emp_sal": 80000}}
)

This updates the emp_sal field to 80000 for documents whose emp_desg is manager.

G. CONNECT MONGODB USING MONGOOSE

Install the packages:

npm install mongoose mongodb


File: app.js

const mongoose = require('mongoose');

// Connection URI to Mongoose
const uri = 'mongodb://127.0.0.1:27017/emp';

// Make database connection (Asynchronously)
mongoose.connect(uri)
    .then(result => {
        console.log('Successful connection!!.....');
    })
    .catch(error => console.log(error));
